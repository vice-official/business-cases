# Business cases
## Project Overview

The **Business Cases Web Application** is a high-performance, modern platform designed for business education. It allows users to listen to detailed business cases with advanced playback controls and multi-language support, while providing administrators with a robust dashboard to manage educational content.

## Core Features
- **Advanced Audio Player:** Playback speed control (1× to 4×) and toggle between Male/Female voices.

- **Localization:** Full interface support for English and Russian.

-  **Dynamic UI:** Light/Dark mode with fluid animations via Framer Motion.

- **Admin Suite:** Full CRUD (Create, Read, Update, Delete) capabilities for chapters and cases.

- **Universal Design:** Fully responsive for mobile, tablet, and desktop.

## User Experience
**Browsing & Listening**

**1.    Sign Up/Login:** Use the buttons in the header to create an account.

**2.    Select a Case:** Browse the library of 6 pre-loaded chapters.

**3.    Playback Controls:** Use the player at the bottom to adjust speed or switch voice genders.

**4.    Read Along:** Full transcripts are provided in both English and Russian for every case.

**Account Management**

Once logged in, your Avatar will appear in the top right. Click it to:

-    View your profile details.

-   Access the Admin Dashboard (if authorized).

-  Log out.

## Administrator Opportunities
**Accessing the Dashboard**

Log in with your admin credentials e.g.:

```
admin@mail.ru
```
Click your avatar and select Admin Dashboard.

As an Admin, your role is to act as the platform's Content Architect. You have full authority to shape the educational experience through a dedicated, secure dashboard.

**Content Control**

- Chapter Management: Create, edit, or delete the main categories. You control the titles (EN/RU), descriptions, and the specific order in which they appear.

- Case Curation: Add business cases with full bilingual transcripts. You map the audio paths for both male and female voices, ensuring the player functions correctly.

- Global Updates: Changes made in your dashboard sync instantly across the site for all users—no code deployments required.

**Oversight & Security**

- User Management: View the list of registered users and their profiles.

- Role Hierarchy: Only you can access the management suite; regular users are restricted to "read-only" access via Row Level Security (RLS).

- Data Integrity: You have the power to prune outdated content and maintain the library's relevance.
